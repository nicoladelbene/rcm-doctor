# 0006 — Synthetic demo RCM with planted defects and ground truth

- Status: accepted
- Date: 2026-11-15

## Context
No client data may be used. The tool must be measurable (verifiability is the brand).

## Decision
A synthetic ~40-control RCM for a fictional Swiss mid-cap (Alpenfirn Industries AG) is generated by script, with ~30% planted defects and a ground-truth label file. The labels double as the eval set.

## Consequences
`npm run eval` reports per-check recall and false-positive rate on clean controls; numbers go in the README.
