# 0013 — Week 1.1: German rules, SoD in the review prompt, holdout v2

**Status:** accepted · 2026-11-15

## Context
Holdout v1 showed the deterministic rules are English-only: German roles ("Leiter …") were read as person names, German
departments and "manuell" were missed, and two SoD phrasings slipped through. The review prompt delegated SoD entirely to rules.

## Decision
- Rules get German role stems, German departments, German manual markers and more SoD patterns (EN + DE).
- Prompt `review.v2` adds an explicit `sod_conflict` assessment. When rule and AI both fire, the rule finding wins (one finding per check).
- Holdout v1 is now "seen" and only reported as a re-run, never as evidence.
- A new holdout v2 is generated by a different family (Gemini) for a new company, after the reviewer is frozen (hashes committed first).
  Generator output that violates the spec (e.g. not exactly 10 German controls) is rejected before writing and logged.
- Each holdout is measured against the previous system as a baseline (git worktree of the earlier commit), same model, same day.
- The token budget for review calls includes reasoning tokens; truncation is an explicit error, not a JSON error.

## Consequences
- German on holdout v2: FP on clean 80% → 0%, recall 81% → 95%. English FP (43%) is unchanged and is the next target.
- Every future fix needs a holdout v3 to be measured honestly.
