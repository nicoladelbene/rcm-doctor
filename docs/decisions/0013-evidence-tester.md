# 0013 — Week 3: evidence tester (tick & tie with verified boxes)

- Status: accepted (on branch week-3)
- Date: 2026-11-15

## Context
ROADMAP Week 3: upload evidence (PDF / screenshot / CSV) for a control; the agent ticks & ties each attribute of the
Week 2 test script, with boxes on the evidence and a reference to the source. Traceability remains the brand, so a box
must never be drawn on text the evidence does not contain.

## Decision
- **Evidence is normalised into a text layer** (`src/core/evidence.ts`): tokens with an id, text and a location —
  a normalised box on a page image (PDF, screenshot) or a cell (CSV). The layer's origin is recorded and shown:
  `generator` (demo, exact), `pdf-text` (the PDF's own text via pdf.js in the browser, exact), `csv` (exact),
  `model-ocr` (screenshot transcribed by the vision model, boxes approximate). Scanned PDFs fall back to `model-ocr`.
- **The LLM (prompt `evidence.v1`, one call per control)** returns, for every sample item × attribute, a result
  (`tick` / `exception` / `not_evidenced` / `n_a`), the token ids it relies on and a verbatim quote. **Code verifies**
  the quote against the cited tokens (or relocates it within the evidence); unverifiable quotes are kept as a warning,
  never as a box. `ALL` lets once-per-control attributes (e.g. a system configuration) apply to every sample.
- **The conclusion is computed by code**: any exception → "exceptions noted"; any not-evidenced → "incomplete".
- **Sample ids come from the auditor** (the pack's `samples`); without them the agent lists the items it found.
- **Privacy**: PDF and CSV parsing happens in the browser; only the text layer (and screenshots) reach
  `/api/evidence` with the user's own key. That route allows 4 MB (screenshots); other routes keep 200 KB.
- **Demo + eval**: synthetic evidence for 5 controls (P2P-05, TRE-01, R2R-01, ITG-05, ITG-06) generated by
  `npm run gen:evidence` (Playwright renders HTML to PDF/PNG and records exact DOM boxes). Two controls carry planted
  exceptions (TRE-01: register updated 6 business days after confirmation; R2R-01: a CHF 1.4m entry without Group
  Controller approval and an approval after posting); clean controls carry near-misses. `npm run eval` now also runs
  `eval:evidence`, gated on: all planted exceptions found, ≤ 5% false exceptions, ≥ 90% of results tied to a box/cell.

## Consequences
Sonnet 5.5: 5 controls in 51 s, 3/3 planted exceptions with the box on the proving token, 0/160 false exceptions,
139/139 ticks/exceptions tied to a verified location. The set is authored with the prompt (regression test, not a
benchmark); an independent evidence holdout is future work. Live uploads cost one call per control (two for
screenshots: transcription, then tick & tie).
