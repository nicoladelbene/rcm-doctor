# 0002 — One flagship repo, growing weekly

- Status: accepted
- Date: 2026-11-15

## Context
Weekly visibility is needed, but a new repo each week dilutes stars, history and narrative.

## Decision
One repo, `rcm-doctor`, grows by one increment per weekend ("Week N"). Each increment gets a Sunday-evening LinkedIn post.

## Consequences
The roadmap lives in docs/ROADMAP.md. Each week must leave the main branch deployable.
